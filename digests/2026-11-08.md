# Engineering Digest — 2026-11-08

Six reads worth your time today. The theme of the day: **progressive collapse, live config, measured RAG**.

## Distributed Systems

### 1. Progressive Collapse in Distributed Systems: Turning the Availability Budget into a Governance Decision — X-Ops (Sam Newman)
https://www.xops.media/en/article/progressive-collapse-distributed-systems-availability-budget-governance

Borrowing from structural engineering, Sam Newman argues that cascading failure is really a governance problem: circuit breakers and second regions cost real money, so someone has to own the trade-off. Grounded in the Oct 2025 DynamoDB DNS outage. For engineers who write postmortems that end in shopping lists.

## Cloud Infrastructure

### 2. Running Databases on Kubernetes in 2026: When You Should (and Shouldn't) — Sharan Sutrapu (Medium)
https://medium.com/@sharansutrapu/running-databases-on-kubernetes-in-2026-when-you-should-and-shouldnt-9c3a528fd570

The old rule said never run a database on Kubernetes; Kubernetes 1.37 and mature operators have changed the calculus. A clear-eyed decision framework for when in-cluster Postgres makes sense and when managed services still win. Published Nov 7, right as KubeCon week opens.

## Java / Spring Boot

### 3. Spring Boot Production Troubleshooting: 15 Real Failure Scenarios and Fixes (2026) — Systems at Scale (Medium)
https://medium.com/engineering-playbook/spring-boot-production-troubleshooting-15-real-failure-scenarios-and-fixes-2026-be3efb955b71

Fifteen scenarios where the symptom lies to you: HikariCP exhaustion with a healthy-looking Postgres, p99 jumps from a lock two layers down, Kafka lag caused by a stuck downstream. Each comes with symptoms, diagnostics, and the likely cause, so you fix the mechanism instead of restarting everything.

### 4. Zero-Downtime Live Config Reloading: Mastering Spring Boot's @RefreshScope in Production — Sumit Patil (Medium)
https://medium.com/@patilsumit/zero-downtime-live-config-reloading-mastering-spring-boots-refreshscope-in-production-78e67b35a599

How to reroute a live HikariCP datasource to a standby cluster, rotate secrets, or retune rate limits without a rolling deploy, using Spring Cloud's @RefreshScope. Covers the lifecycle mechanics that cause memory leaks and race conditions if you use it naively. For teams whose restarts are expensive.

## Applied AI / RAG

### 5. Papers Suggest. Evals Decide. — Radhika Singh (Medium)
https://radhikaaaaaa.medium.com/papers-suggest-evals-decide-c67044be886d

Instead of trusting paper claims, the author built a small sandboxed RAG harness and measured each idea: query rewriting lifted accuracy from 0.40 to 0.83, a cross-encoder reranker raised MRR to 0.97 at 35% latency cost, and graph-only retrieval underperformed. Small numbers, honestly caveated, and exactly the habit production RAG work needs.

### 6. Scaling RAG Systems: From Basic Vector Search to Production-Grade Retrieval — Victor Asel (Medium)
https://medium.com/@victaasel/scaling-rag-systems-from-basic-vector-search-to-production-grade-retrieval-d57272eb782f

A production RAG system is an ingestion pipeline, not a demo: restartable and idempotent indexing, two-stage retrieve-then-rerank, hybrid lexical-plus-vector search with reciprocal rank fusion, and hallucination detection with LLM-as-judge. Good for teams whose prototype works and whose users are about to find out.
