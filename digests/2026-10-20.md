# Engineering Digest — 2026-10-20

Six pieces on the gaps between checks and reality: schema compatibility that forgets the past, cost cuts that bite back, migrations that rename your dependencies, and agent architectures built for production. The theme of the day: **checks that pass, systems that fail**.

## Distributed Systems

### 1. Our Kafka Schema Passed Every Compatibility Check. A Six-Month-Old Event Still Broke Production. — Devrim Ozcay
https://medium.com/engineering-playbook/our-kafka-schema-passed-every-compatibility-check-a-six-month-old-event-still-broke-production-5be46efb27aa

Compatibility checks pass, then a six-month-old event blows up a consumer anyway. A good tour of the Kafka replay gap: schema rules validate the future, not the archived past your consumers still re-read.

## Java/Spring Boot

### 2. Spring Boot 4: some pitfalls to watch for when migrating in Java — Felipe Ventura
https://medium.com/@venturafelipe/spring-boot-4-some-pitfalls-to-watch-for-when-migrating-in-java-0068b44c56e9

Practical migration notes from Spring Boot 3.5 to 4: the spring-boot-starter-aop rename to starter-aspectj and the new split data-jpa-test starter with changed imports. Short, concrete, and worth skimming before you bump the version.

## Cloud Infrastructure

### 3. We Cut Our AWS Bill by 37%. Then Kubernetes Started Killing Our Services. — Devrim Ozcay
https://devrimozcay.medium.com/we-cut-our-aws-bill-by-37-then-kubernetes-started-killing-our-services-bf984c9c9a0d

A team cut its AWS bill 37% by shrinking Kubernetes requests and nodes, then watched latency climb. Illustrates the real trade-off behind cost PRs: request sizing is a production bet, not just arithmetic. (Marked as a fictionalized case study, but the failure mode is real.)

## Applied AI

### 4. Architecting Event-Driven Multi-Agent Systems in 2026: Patterns, State Management, and Production Failures — syuthd.com
https://www.syuthd.com/2026/10/architecting-event-driven-multi-agent.html

A patterns guide for running multi-agent systems on event buses: saga compensation for failed agent tasks, separating agent scratchpads from durable state, and OpenTelemetry tracing across async agent hops. Solid architecture thinking for agentic pipelines.

### 5. We Shipped 10 AI Agents to Production. Here's What Actually Worked — Codersarts
https://codersarts.medium.com/we-shipped-10-ai-agents-to-production-heres-what-actually-worked-42718b321268

Lessons from shipping ten AI agents: finite-state machines with hard iteration caps, micro-agents coordinated by a deterministic supervisor, two-phase commits for write tools, and human approval cards for the last 10%. Disciplined engineering over autonomous hype.

## RAG

### 6. RAG Best Practices for 2026 — AgentFlare Research
https://agentflare.org/research/rag-best-practices-for-2026.html

A compact 2026 field guide: start with naive RAG (it fits ~80% of apps), add query rewriting and re-ranking only when your data proves it necessary, and track retrieval metrics like recall@5 separately from answer quality. The cheapest architecture that meets your bar is the right one.
