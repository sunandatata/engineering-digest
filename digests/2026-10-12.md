# Engineering Digest — 2026-10-12

Postmortems from GitHub and Cadence, the ugly truth about your GPU bill, and why RAG systems die at ingestion. The theme of the day: **postmortems, GPU waste, RAG hardening**.

## Distributed Systems

### 1. Incident with Actions: GitHub Actions degraded by datacenter–cloud network failure — GitHub (via postmortem.io)
https://postmortem.io/incidents/github--2026-10-05--actions-hosted-runners-datacenter-cloud-network-failure/

A partial datacenter-to-cloud network failure took GitHub-hosted runners down to a 47% failure rate at peak — but Pages and self-hosted runners were untouched. A sharp reminder that multi-region connectivity is its own blast-radius problem, separate from your app's logic.

### 2. Nothing Crashed. We Quietly Sent 83,000 Customers the Wrong Data. — Dev Yusuf Seyitoglu
https://medium.com/@yusufseyitogluu/nothing-crashed-we-quietly-sent-83-000-customers-the-wrong-data-cf6f69a9d420

A one-line cache change dropped the tenant ID from the cache key and served one customer's data to 83,000 others — with every health signal green. If your cache key doesn't include every authorization dimension, you don't have a performance optimization, you have a leak.

### 3. Two Hidden Deadlocks in Cadence Matching: 1 Day, 2 Engineers, 6 Lines of Code — Jakob H. and Eleonora D. (Cadence)
https://github.com/cadence-workflow/cadence-docs/blob/HEAD/blog/2026-04-20-shard-manager-incident/2026-04-20-shard-manager-incident.mdx

Cadence's new shard manager replaced hash-ring routing and, during rollout, surfaced two latent goroutine deadlocks in the matching service — diagnosed and fixed in 6 lines by 2 engineers. Observability in the routing layer paid for the whole migration by itself.

## Java / Spring Boot

### 4. Core Java vs Enterprise Java: Jakarta EE & Spring Boot 2026 — Harness
https://www.harness.io/blog/jakarta-ee-vs-spring-boot

A grounded decision guide: Spring Boot is still the path of least resistance for most greenfield microservices, Quarkus wins cold-start/serverless, and Java 21 is the 2026 baseline with Java 25 as the migration target. Useful reference when your team is debating a stack move.

## Cloud Infrastructure

Cast.ai's October 2026 report measured 23,000 real clusters and found 5% average GPU utilization — you're paying for ~20x more GPU than you use, with AKS at a brutal 2%. If you're running AI workloads on Kubernetes, this is your budget conversation starter.

## Applied AI / RAG

### 6. How I'd Design a Production RAG System from Scratch — LLD, System Design, and MLOps All at Once — AJ
https://medium.com/@adityaj5400/how-id-design-a-production-rag-system-from-scratch-lld-system-design-and-mlops-all-at-once-1b96cd6c5537

A from-scratch production RAG design that actually covers the unglamorous parts: sharded vector indices, in-house embedding inference at 4x cost savings, hierarchical two-stage retrieval, and the reminder that the gap between a prototype and a product is engineering discipline, not models.

### 7. PDFs Are for Humans, Not LLMs: The Cold Hard Truth About RAG in Production — Rozêra
https://medium.com/@rozxalil801/pdfs-are-for-humans-not-llms-the-cold-hard-truth-about-rag-in-production-07aae0f4f980

RAG systems usually fail at ingestion, not retrieval: naive PDF text extraction collapses tables, pollutes chunks with headers, and your vector DB happily indexes the wreckage. A short argument for treating document parsing as a first-class engineering problem.
