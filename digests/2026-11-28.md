# Engineering Digest — 2026-11-28

Six reads on the failures that stay quiet until they cost you: data that corrupts silently, Spring config that only bites in production, and RAG systems that need measuring before they need tuning. The theme of the day: **silent corruption, Spring traps, and the RAG eval gap**.

## Distributed Systems

### 1. 70 Advanced Production Failures That Can Silently Corrupt Distributed Systems — Inside Backend Engineering
https://medium.com/engineering-playbook/70-advanced-production-failures-that-can-silently-corrupt-distributed-systems-63804d38dab9

Seventy ways a distributed system can lose or corrupt data without raising an alarm — lost commits on async failover, WAL timelines replayed wrong, Kafka leaders exposing uncommitted entries. A field guide to the failure modes that only show up when real money or real customer data is at stake.

### 2. 6 System Design Problems That Expose Engineers Who Have Never Owned Production — Engineering Unfiltered
https://medium.com/engineering-playbook/6-system-design-problems-that-expose-engineers-who-have-never-owned-production-cde772b557af

Retry amplification, queues that hide overloaded consumers, pools that starve critical requests — six design problems where textbook answers fail and production experience shows. The retry-budget framing alone is worth the read for anyone designing a microservice platform.

## Java / Spring Boot

### 3. 12 Spring Boot Configuration Mistakes That Become Expensive in Production — Inside Backend Engineering
https://medium.com/engineering-playbook/12-spring-boot-configuration-mistakes-that-become-expensive-in-production-235fa1f8b23c?source=rss------programming-5

An app that starts fine is not an app that is ready for traffic: missing HTTP timeouts, HikariCP sized without counting replicas, Hibernate left free to mutate the schema, every actuator endpoint exposed. A pre-flight checklist for Spring Boot services about to meet real customers.

### 4. Senior Java & Spring Boot Production Debugging: 25 Failures Every Backend Engineer Must Master — Architecture Unfiltered
https://medium.com/engineering-playbook/senior-java-spring-boot-production-debugging-25-failures-every-backend-engineer-must-master-b5aa6988cfc2

From HikariCP exhaustion and @Transactional self-invocation to JVM heap growth that is not a leak and Kubernetes OOMKills with free heap — 25 failure patterns with SQL diagnostics, JVM commands, and recovery strategies. The kind of catalog you want read before the 2am page, not during it.

## Applied AI / RAG

### 5. RAG Pipelines for Platform Teams: Vector Stores, Chunking, and Evaluation — Yuval Glasman, Platform Monkey
https://platform-monkey.com/guides/rag-pipeline-platform-engineering

A reference architecture for production RAG on the verified late-2026 stack — Qdrant 1.20 native BM25, voyage-4, RAGAS 0.4 — with chunking strategy, vector store selection, a CI-wired eval harness, complete Kubernetes manifests, and cost math from live rate cards. The rare RAG guide that names exact versions and real numbers.

## Cloud Infrastructure

### 6. Kubernetes Cost Optimization 2026: Cut 40% Year-End — ITSourceCode
