# Engineering Digest — 2026-11-06

Six reads worth your time today. The theme of the day: **cascading failures, CAP trade-offs, and EKS at scale**.

## Distributed Systems

### 1. One Failed API Request Can Bring Down an Entire System — tiwarisuhani_11
https://medium.com/@tsuhani434/one-failed-api-request-can-bring-down-an-entire-system-e07c81bbc915

A single slow dependency can cascade into a full outage when retries, timeouts, and thread pools all amplify the same failure. A clear walkthrough of cascading failures, exponential backoff with jitter, circuit breakers, and why only idempotent calls are safe to retry. For anyone who owns a service that calls other services.

### 2. Coordination, CAP, and PACELC: How Distributed Systems Agree Under Failure — Paresh Yadav
https://medium.com/@pareshyadav.ksp/coordination-cap-and-pacelc-how-distributed-systems-agree-under-failure-5a3b27322c0c

Leader election, distributed locks, and consensus distilled into one piece, then grounded in the trade-offs real databases make: DynamoDB, Spanner, and Cosmos DB under CAP and PACELC. Good for engineers who know the theorems but want to see how they show up in systems they actually run.

## Java / Spring Boot

### 3. Spring Boot Microservices in 2026: 9 Architecture Mistakes That Can Destroy Your Production System — Software Engineering Knowledge
https://medium.com/engineering-playbook/spring-boot-microservices-in-2026-9-architecture-mistakes-that-can-destroy-your-production-system-634773179be1

Spring Boot makes the wrong architecture easy: synchronous HTTP chains between services, @Transactional treated as a distributed guarantee, and Kafka consumers that re-apply events after a crash. Nine mistakes that look reasonable in a code review and only bite under real traffic, with the fixes. For Spring teams moving to microservices.

### 4. Spring Boot @Transactional Not Working? 7 Production Bugs That Catch Experienced Java Developers — SYSTEM DESIGN & Java Spring Boot
https://medium.com/engineering-playbook/spring-boot-transactional-not-working-7-production-bugs-that-catch-experienced-java-developers-1a6bab629465

Self-invocation bypassing the proxy, checked exceptions that don't roll back, exceptions swallowed before rollback, and @Async escaping the transaction context — seven ways @Transactional silently does less than you think. A compact checklist to run against your own codebase before production finds the gaps for you.

## Cloud Infrastructure

### 5. Scaling & Upgrading Amazon EKS: Practical Guide for 100+ Microservices Running on 20 Nodes — Pankaj Aswal
https://iampankajaswal.medium.com/scaling-upgrading-amazon-eks-practical-guide-for-100-microservices-running-on-20-nodes-bffd2429dfcf

What changes when you run 100 microservices on 20 EKS nodes: scaling the application before the cluster, HPA and Karpenter working together, and a step-by-step control-plane upgrade from Kubernetes 1.32 to 1.33 without downtime. Practical and numbers-grounded, for teams whose cluster has outgrown the tutorial stage.

## Applied AI / RAG

### 6. What Production RAG Needs That the Demo Doesn't — _Prav
https://techdelta.medium.com/what-production-rag-needs-that-the-demo-doesnt-32373e32d4df

Lessons from running retrieval inside live phone calls, where documents are untrusted, one index is shared across customers, and a wrong answer arrives with total confidence. Essential reading before your RAG demo meets real users.
