# Engineering Digest — 2026-11-24

Six reads on the failures that stay quiet until they don't — and the discipline that catches them. The theme of the day: **silent failures, honest bills, versioned retrieval**.

## Distributed Systems

### 1. 70 Advanced Production Failures That Can Silently Corrupt Distributed Systems — Inside Backend Engineering
https://medium.com/engineering-playbook/70-advanced-production-failures-that-can-silently-corrupt-distributed-systems-63804d38dab9

A field guide to the failure modes that never page you: lost commits on async failover, WAL retention eating disk, Kafka offsets advancing before state is durable. Worth reading before you trust a green dashboard — the corruption cases here are the ones postmortems are written about.

## Java / Spring Boot

### 2. Senior Java & Spring Boot Production Debugging: 25 Failures Every Backend Engineer Must Master — Architecture Unfiltered
https://medium.com/engineering-playbook/senior-java-spring-boot-production-debugging-25-failures-every-backend-engineer-must-master-b5aa6988cfc2

HikariCP exhaustion with a healthy database, @Transactional silently failing on self-invocation, JVM heap growth that isn't a leak, OOMKills with free heap. A practical checklist of the Spring Boot traps that pass every test and bite in production — for anyone who owns a Java service on call.

## Distributed Systems

### 3. Real Time Is the Easy Part: Lessons from Building Data Streaming Platforms at Scale — Improving
https://medium.com/@improving-enterprises/real-time-is-the-easy-part-lessons-from-building-data-streaming-platforms-at-scale-8d8893b499fd

Getting the first event flowing is the easy part; day two is when observability collapses, dead-letter queues fill silently, and partition rebalancing breaks ordering. The useful framing here is 'effectively once' over exactly once — idempotent consumers beat broker guarantees for real business outcomes.

## Cloud Infrastructure

### 4. How I cut our cloud bill by 82% in four weeks, and what it cost us — scnozdemir
https://medium.com/@scnozdemir/how-i-cut-our-cloud-bill-by-82-in-four-weeks-and-what-it-cost-us-9c4a22e1ea2d

A real teardown with real invoices: $1,472/month down to about $267, across 75 pull requests, by sizing Kubernetes requests to measured use instead of guesses. Honest about the trade-offs too — single-node production, no staging. The rare cost-cutting story that shows what you give up, not just what you save.

## Applied AI / RAG

### 5. Retrieval in Production: The Index as a Versioned Artifact — Kinda Technical
https://kindatechnical.com/mlops-guide/rag-pipelines-in-production-indexing-retrieval-and-evaluation.html

Four customer-facing retrieval failures, none of them model problems — all of them a derived index drifting from its source with no versioning or tests. The fix: treat the index like a release — versioned, gated by evaluation, swapped atomically, rolled back the same way. Essential reading if your RAG system is past the demo stage.

### 6. The State of Agentic Infrastructure 2026: From BGP Routing Tables to Autonomous AI Control Planes — VirtualSach
https://www.virtualsach.in/blog/2026-11-state-of-agentic-infrastructure-2026/

The argument: enterprise AI is a distributed systems problem wearing a prompt-engineering costume. Recursive retry storms burning $10k in tokens overnight, agents with unattenuated credentials, $47k/month billing surprises — all map to primitives networking engineers solved decades ago: circuit breakers, TTLs, cost-aware routing. A strong mental model for anyone running agents in production.
