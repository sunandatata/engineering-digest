# Engineering Digest — 2026-11-05

Six reads worth your time today. The theme of the day: **retry budgets, Spring proxies, and production RAG**.

## Distributed Systems

### 1. Retries Are Quietly Destroying Your Distributed System. And Your Code Thinks It's Helping. — Sarthak Niwate
https://info-sarthakfeeds.medium.com/retries-are-quietly-destroying-your-distributed-system-and-your-code-thinks-its-helping-15617445ca56

A retry policy set per service looks like resilience, but under load every service's retries multiply the same traffic — a system doing 10,000 requests can suddenly face 40,000 to 60,000 attempts. Worth reading if you set retry counts in isolation: it argues for deadline-aware, budget-controlled retries, and a 'retry passport' that tracks the extra work recovery itself creates.

### 2. More Executors, Same Slow Job: The Hidden Cost of Data Skew? — chandrasekhar naidu
https://medium.com/@gullashekar/more-executors-same-slow-job-the-hidden-cost-of-data-skew-ef4a9cc22edf

Adding executors to a slow Spark job does nothing when one hot partition holds 30 GB while the ideal is 250 MB — parallelism only helps when the work is actually divisible. A clear, numbers-driven walkthrough of why skewed keys cap your speedup, and the salting pattern that fixes it. For anyone tuning distributed pipelines.

## Java / Spring Boot

### 3. 10 Spring Boot Annotations That Do More Than You Think — Naveen Metta
https://naveen-metta.medium.com/10-spring-boot-annotations-that-do-more-than-you-think-94ad7278a091

Annotations like @Transactional, @Async, and @Cacheable look like labels but generate proxies, wrap threads, and sometimes run extra SQL — and self-invocation silently skips all of it. A practical tour of the ten most misunderstood annotations, grounded in production debugging stories. For every Spring developer who has wondered why a rollback didn't happen.

### 4. How Spring Boot Auto-Configuration Actually Works — Ankit Verma
https://medium.com/javarevisited/how-spring-boot-auto-configuration-actually-works-8c3faaa8184d

Goes one layer below the magic: how @EnableAutoConfiguration and the @Conditional system decide which beans exist before you write a single @Bean method, and how the mechanism changed in Spring Boot 4. Read it the next time auto-configuration disagrees with you and --debug output is your only friend.

## Cloud Infrastructure

### 5. Zero-Downtime Live Config Reloading: Mastering Spring Boot's @RefreshScope in Production — Sumit Patil
https://medium.com/@patilsumit/zero-downtime-live-config-reloading-mastering-spring-boots-refreshscope-in-production-78e67b35a599

When a primary database cluster degrades at peak traffic, @RefreshScope lets you reroute a live HikariCP pool to a standby cluster in seconds — no rolling deploy, no dropped sessions. The piece covers the refresh lifecycle, memory-leak and race-condition traps, and the failover and secret-rotation use cases where it earns its keep.

## Applied AI / RAG

### 6. From Demo to Production: How to Make Your RAG System Production-Ready — Atharva Kulkarni
https://medium.com/@atharva.kulkarni2427/from-demo-to-production-how-to-make-your-rag-system-production-ready-cda0a3e68f5e

A basic chunk-embed-retrieve pipeline demos well and fails in production; this walks through nine upgrades that close the gap — chunk sizing and strategy, embedding benchmarks on your own questions, hybrid search with RRF, query rewriting, reranking, and evals in CI. The framing that most hallucinations are really retrieval failures is the takeaway to keep.
