# Engineering Digest — 2026-11-27

A week of outages and hard-won production numbers: what breaks on day two, why cold starts and virtual threads betray you, and why RAG quality is decided before the model ever runs. The theme of the day: **when recovery spreads failure and retrieval sets the ceiling**.

## Distributed Systems

### 1. Real Time Is the Easy Part: Lessons from Building Data Streaming Platforms at Scale — Improving
https://medium.com/@improving-enterprises/real-time-is-the-easy-part-lessons-from-building-data-streaming-platforms-at-scale-8d8893b499fd

Getting the first event through is easy; the pain starts on day two with dead-letter queues, unreconciled events, and ordering that breaks on rebalance. A practical guide to the observability and delivery-guarantee trade-offs that decide whether a streaming platform survives real adoption.

### 2. Multi-Region System Design: 21 Production Failures Senior Engineers Must Understand — Inside Backend Engineering
https://medium.com/engineering-playbook/multi-region-system-design-21-production-failures-senior-engineers-must-understand-081c36090707

Two regions can both accept the same payment and both be convinced they are right. Walks through active-active consistency, fencing tokens, and failover that recovers infrastructure but loses business correctness — the failure modes architecture diagrams hide.

## Java / Spring Boot

### 3. Spring Boot 4 + Java 25 on Cloud Run: 62% faster cold starts — Arun Shinde, Google Cloud Community
https://medium.com/google-cloud/spring-boot-4-java-25-on-cloud-run-62-faster-cold-starts-b0b39e5cf999

A legacy Spring Boot service went from 13.2s to 5.0s median cold start, with each of ten changes measured separately — the JDK 25 AOT cache alone saved 4.4s, and one popular trick actually made startup worse. For anyone running Java serverless and paying for every cold start.

### 4. Our Java 21 Virtual Threads Handled 100,000 Requests. Production Collapsed at 8,000 — Systems at Scale
https://medium.com/@devrimcoder/our-java-21-virtual-threads-handled-100-000-requests-production-collapsed-at-8-000-5f28c61c37de

Load tests passed with 100,000 concurrent virtual threads; production fell over at 8,000 as HikariCP acquisition times hit 30 seconds. Virtual threads removed a concurrency limit the old thread pool had been enforcing by accident — a cautionary tale about pool sizing and backpressure.

## Applied AI / RAG

### 5. RAG in Production: Retrieval Is Data Engineering, Not a Prompt Trick — André Claudino
https://medium.com/@andrelgcclaudino/rag-in-production-retrieval-is-data-engineering-not-a-prompt-trick-d07c3defe223

Your grounded answer can never be better than the retrieval that fed it. Covers chunking as a design decision, Recall@K as the metric that matters, reranking before generation, and building a golden set of 50–200 question-passage pairs as a living eval asset.

## Cloud Infrastructure

### 6. Cloud Outage Statistics 2026: How Often AWS, Azure and Google Cloud Go Down, Why, and What It Costs — Speaking of Clouds
https://www.speakingofclouds.com/cloud-outage-statistics/

Downtime now costs the Global 2000 about $600 billion a year, and 65.8% of provider outages with a stated cause started with a change the provider itself made. Data-rich survey of 123 post-incident reports — useful ammunition for resilience budgets and multi-region arguments.
