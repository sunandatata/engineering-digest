# Engineering Digest — 2026-10-21

Six pieces on knowing your numbers: measured API limits, migrating 85 services without repeating mistakes, debugging production the hard way, and serving LLMs across 17,000 nodes. The theme of the day: **measured limits, fleet migrations, and inference at scale**.

## Java/Spring Boot

### 1. Your Spring Boot 4 API Works Until Someone Asks for 5 Million Rows: 8 Limits That Stop Unbounded Work, Measured — Navya Devadiga (Boot Camp Java)
https://medium.com/boot-camp-java/your-spring-boot-4-api-works-until-someone-asks-for-5-million-rows-8-limits-measured-fd0f8c46a562

A findAll() on 5M rows OOMs in 8.9s on a 512MB heap while a streamed export peaks at 78MB — eight guardrails against unbounded endpoints, each one measured on Spring Boot 4 with embedded Postgres. The kind of piece to read before your table grows.

### 2. Migrating 85 microservices from Spring Boot 2.6 & Java 17 to Spring Boot 4.1 & Java 25: solve every error once — ce.mahmut
https://medium.com/@ce.mahmut/migrating-85-microservices-from-spring-boot-2-6-001455c68108

The insight is the method, not the migration: the expensive part of a fleet move is solving the same error 85 times, so they built an open-source toolkit that fixes chronic errors once. Phase 1 done — 17 services live, 6,880 tests green, 150+ errors solved permanently.

## Distributed Systems

### 3. Google Cloud ships llm-d 1.0: Smart TPU/GPU Routing — AI Daily Post
https://aidailypost.com/news/google-cloud-ships-llm-d-10

Google's open-source Kubernetes-native stack for distributed LLM inference, with cache-aware routing across TPU/GPU pools instead of naive round-robin — validated on a 17,000-node GKE benchmark. Serving models at scale is now its own engineering discipline.

### 4. I Wouldn't Hire a Senior Backend Engineer Who Can't Debug This Production Failure — Engineering Playbook (ProdRescue Devrim)
https://medium.com/engineering-playbook/i-wouldnt-hire-a-senior-backend-engineer-who-can-t-debug-this-production-failure-ffabe9080ce1

A Spring Boot debugging exercise where latency jumps from 80ms to 12s with CPU at 28% and Postgres looking fine: HikariCP exhaustion, lock contention, K8s scaling, retry storms. The mechanisms are real — use it to test whether you reason about systems or just symptoms.

## Cloud Infrastructure

### 5. GKE vs EKS without a platform team: 7 ways to run Kubernetes in 2026 (ranked) — Qovery
https://www.qovery.com/blog/gke-vs-eks-without-a-platform-team-ranked

A ranked tour of Kubernetes options for teams without platform engineers, from Cloud Run and App Runner up to managed clusters. The honest rule stands out: start serverless and move to Kubernetes at the first requirement serverless cannot meet, not before.

## AI/RAG Engineering

### 6. AI Metrics for Mere Mortals, Part 2: How to Measure Search, RAG, and Generated Answers — Adnan Masood, PhD.

Precision@K, NDCG, faithfulness, and answer correctness each worked by hand on small examples — including why a faithfully grounded answer can still be wrong. A practical foundation for anyone building RAG evals instead of trusting vendor demo numbers.
