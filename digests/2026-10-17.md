# Engineering Digest — 2026-10-17

Six reads worth your time today. The theme of the day: **client-side outages, Java 25 migration, production RAG**.

## Distributed Systems

### 1. The Pulse: Firebase's Global Outage and Poor Response — Pragmatic Engineer newsletter (Gergely Orosz)
https://newsletter.pragmaticengineer.com/p/the-pulse-firebases-global-outage-213

A routine config cleanup crashed a huge share of iOS apps — while every status dashboard stayed green, because dashboards only watched server-side health. A sharp lesson on validating config payloads client-side and monitoring the client, not just the servers.

### 2. Ten AI Agents Destroyed Production Data. Not One Vendor Published a Postmortem. — Chen Yuan, Medium
https://medium.com/@chenyuan19920509/ten-ai-agents-destroyed-production-data-not-one-vendor-published-a-postmortem-8907211a68d2

Ten documented cases of AI coding agents wiping or breaking production data — Replit, Cursor, Kiro — and not one vendor published a postmortem. Essential reading on the permission models, two-person gates, and irreversibility handling that agentic tooling still lacks.

## Java / Spring Boot

### 3. Spring Boot on Java 25: Migration, Performance, and What Breaks — Prince Yadav, Medium
https://medium.com/@princeyadav7901/spring-boot-on-java-25-migration-performance-and-what-breaks-85b969e0d0cb

A practical migration playbook for Spring teams moving to Java 25 LTS: update Lombok, Byte Buddy and Hibernate first, then load-test virtual threads and check JFR for pinning events. The key point — migrate in separate steps and measure your own workload, because the JDK change is the easy part.

### 4. Our Spring Boot App Handled 10x Traffic After I Deleted 6 Dependencies — FutureLens, CodeX (Medium)
https://medium.com/codex/our-spring-boot-app-handled-10x-traffic-after-i-deleted-6-dependencies-a02dce4c1ac3

Load-test numbers tell the story: 1,000 req/min struggling to 10,000 req/min comfortable, just by deleting six accumulated dependencies — no Redis, no bigger instances. A good reminder to profile dependency bloat before reaching for more infrastructure.

## Applied AI / RAG

### 5. RAG in Production: 7 Lessons from Shipping It — FreshCodes
https://freshcodes.net/blog/rag-in-production-7-lessons-from-shipping-knowledge-assistants

Seven battle-tested lessons from shipping RAG to production: structure-aware chunking beats model upgrades, hybrid vector+BM25 search halved hallucinations, and most 'the model is wrong' bugs are really 'the model never saw the right document.' Comes with a concrete golden-dataset and per-request cost budget playbook.

### 6. RAG Becomes an Engineering Pattern: Tooling and Retrieval Trade-offs — Particle News
https://particle.news/story/rag-becomes-an-engineering-pattern-with-clear-tooling-and-retrieval-tradeoffs

A survey of how RAG has settled into a two-phase engineering pattern — offline indexing plus query-time retrieval — with the real bottleneck clearly identified as retrieval quality, not generation. Includes a Spring AI + Spring Boot code walkthrough and the trade-offs of switching from in-memory stores to PGVector or Qdrant.
